# A Monstrous Compendium, Reforged

Enhanced Creatures brings every monster in Baldur's Gate and Baldur's Gate II: Enhanced Edition closer to its Pen &amp; Paper roots, using a mix of 2nd and 3rd edition rules.

## About

Its main purpose is to bring all monsters as close as possible to <abbr title="Pen and Paper">P&amp;P</abbr> using a mix of 2nd and 3rd edition rules.

This mod has a long history &mdash; work started between 2005 and 2011, but the scope was too large to reach the intended quality at the time. In 2025, development restarted from scratch with new ideas. It began as a strong fork of aTweaks, though most of the code has since been rewritten.

## PnP Monsters

This is a work in progress, many monsters haven't covered yet.

Monsters are heavily patched and since many popular mods are covered, it might break a few things. New scripts are inserted last (going up from default script), which should reduce risks. Generic scripts are removed and some specifics are edited when needed.

Also, it will probably tone down some monsters with illegal stats. To mitigate this, monsters are getting adjustments which can greatly increase their challenge while sticking as much as possible to the rules.

A lot of time went into categorizing monsters by general, race, class, animation, weapons, and even dialog. If you think a creature has been miscategorized, feel free to [report it](https://github.com/arnaudpourbaix/enhanced-creatures/issues) and it will be reviewed.

## Install

[Download the latest release](https://github.com/arnaudpourbaix/enhanced-creatures/releases/tag/latest). WeiDU is not shipped with the release yet, so you have to use your own.

It should be installed very late, and especially after SCS.

## Compatibility

Don't use **Use BG Walking Speeds** from The Tweaks Anthology &mdash; it will break monster movement calculations.
