# Enhanced Creatures Mod Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 3-page, D&D/Baldur's Gate-themed website in `docs/` (landing page, re-themed monster compendium, new changelog page) served from GitHub Pages.

**Architecture:** A shared `docs/assets/site.css` defines the parchment theme (colors, fonts, nav bar, card primitives) as CSS custom properties, consumed by a hand-authored `docs/index.html`, the existing generated `docs/monsters.html` (re-themed via its generator templates + new `docs/monsters.css`/`docs/monsters.js`), and a new generated `docs/changelog.html` (built by a new `changelogService` that converts a root `CHANGELOG.md` to HTML with `marked` and injects it into a new template).

**Tech Stack:** Static HTML/CSS/vanilla JS for the site; TypeScript (existing `generator/` project, vitest) for the changelog generation step; `marked` (new dependency) for Markdown → HTML.

## Global Constraints

- Not affiliated with Gibberlings3 — no G3 branding, assets, or CSS are reused; `stratagems/doc/readme-stratagems.html` was structural reference only.
- Fixed palette: background `#f2e4c2`, ink text `#3b2a17`, ink-soft/headings `#5c3d17`, gold `#b8860b`, red accent `#8b1a1a`, panel `#e8d6ac`, nav background `#e3cd9a`.
- Fixed fonts: **Cinzel** for headings/nav/site title, **Lora** for body text, both loaded via a Google Fonts CDN `<link>` (no vendoring).
- The shared top nav (`⚔ Enhanced Creatures` · Home · Monsters · Changelog) is duplicated by hand in all three page templates — no shared include mechanism exists for static HTML here.
- `docs/monsters.html`, `docs/monsters.css`, `docs/monsters.js`, and `docs/changelog.html` are build outputs regenerated by `npm run generate` in `generator/` — never hand-edit them directly; edit the templates/services instead.
- No dark mode, no search/filter additions to the monsters page, no GitHub Pages CI/workflow setup (out of scope).
- `pipeline.golden.test.ts` must keep passing: it needs `CHANGELOG.md` copied into its temp fixture directory and `docs/changelog.html` added to its `FIXED_GENERATED_FILES` list.
- Running `npm run generate` regenerates the entire creature pipeline (WeiDU/BAF scripts get non-deterministic re-shuffled target ordering by design — see `generator/README.md`). When committing, stage only the files this plan intentionally touches (`docs/**`, `CHANGELOG.md`, `generator/lib/templates/**`, `generator/lib/src/services/**`, `generator/package.json`, `generator/package-lock.json`) — never `git add -A`/`git add .` — so incidental regeneration churn in unrelated files (`lib/pnp-monster/**`, `tra/**`, `lib/common/**`, `generator.log`) is left alone.

- [ ] **Step 5: Implement the service**

Create `generator/lib/src/services/doc/changelog.service.ts`:

```typescript
import * as fs from "fs";
import * as path from "path";
import { marked } from "marked";
import { State } from "../../state";
import logService from "../log.service";
import utils from "../utils/utils.service";

class ChangelogService {
  generate() {
    logService.log("Generating changelog documentation");
    const changelogPath = path.join(State.modFolder, "CHANGELOG.md");
    let markdown: string;
    try {
      markdown = fs.readFileSync(changelogPath).toString();
    } catch (e) {
      throw new Error(`Failed to read ${changelogPath}`, { cause: e });
    }
    let templateText: string;
    try {
      templateText = fs.readFileSync("lib/templates/changelog.html").toString();
    } catch (e) {
      throw new Error(`Failed to read template lib/templates/changelog.html`, {
        cause: e,
      });
    }
    const html = this.render(templateText, markdown);
    try {
      utils.writeFile("docs/changelog.html", html);
    } catch (e) {
      throw new Error(`Failed to write documentation to docs/changelog.html`, {
        cause: e,
      });
    }
  }

  render(templateText: string, markdown: string): string {
    const template = { text: templateText };
    this.replace(template, "changelog", marked.parse(markdown) as string);
    return template.text;
  }

  private replace(template: { text: string }, key: string, value: string) {
    key = `{{${key}}}`;
    if (!template.text.includes(key)) throw new Error(`Token ${key} not found !`);
    template.text = template.text.replace(new RegExp(key, "g"), value);
  }
}

const changelogService = new ChangelogService();
export default changelogService;
```

### Task 8: Monsters page behavior (`docs/monsters.js`)

**Files:**
- Create: `docs/monsters.js`

**Interfaces:**
- Consumes: `.menu-toggle` / `.sidebar` / `.backdrop` from Task 6's template and Task 7's `.open`/`.visible` CSS; `.spellbook-tabs` / `.spellbook-tab-button[data-tab]` / `.spellbook-tab-panel[id]` markup produced by `documentation.service.ts`'s `getCreatureSpellbooks`.
- Produces: none consumed elsewhere — this is the last piece wiring existing markup/CSS together.

- [ ] **Step 1: Create the script**

Create `docs/monsters.js`:

```javascript
(function () {
  "use strict";

  function initSidebarToggle() {
    var toggle = document.querySelector(".menu-toggle");
    var sidebar = document.querySelector(".sidebar");
    var backdrop = document.querySelector(".backdrop");
    if (!toggle || !sidebar || !backdrop) return;

    function closeSidebar() {
      sidebar.classList.remove("open");
      backdrop.classList.remove("visible");
      toggle.setAttribute("aria-expanded", "false");
    }

    function toggleSidebar() {
      var isOpen = sidebar.classList.toggle("open");
      backdrop.classList.toggle("visible", isOpen);
      toggle.setAttribute("aria-expanded", String(isOpen));
    }

    toggle.addEventListener("click", toggleSidebar);
    backdrop.addEventListener("click", closeSidebar);
    sidebar.addEventListener("click", function (event) {
      if (event.target.closest("a")) closeSidebar();
    });
  }

  function initSpellbookTabs() {
    document.querySelectorAll(".spellbook-tabs").forEach(function (tabs) {
      var buttons = tabs.querySelectorAll(".spellbook-tab-button");
      buttons.forEach(function (button) {
        button.addEventListener("click", function () {
          var targetId = button.getAttribute("data-tab");
          buttons.forEach(function (b) {
            b.classList.toggle("active", b === button);
          });
          tabs.querySelectorAll(".spellbook-tab-panel").forEach(function (panel) {
            panel.classList.toggle("active", panel.id === targetId);
          });
        });
      });
    });
  }

  document.addEventListener("DOMContentLoaded", function () {
    initSidebarToggle();
    initSpellbookTabs();
  });
})();
```
