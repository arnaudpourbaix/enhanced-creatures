# Enhanced Creatures

![GitHub release (latest by date)](https://img.shields.io/github/v/release/arnaudpourbaix/enhanced-creatures)

Enhanced Creatures for Baldur's Gate EE and Baldur's Gate 2 EE: bringing all monsters as close as possible to P&P using a mix of 2e and 3e edition rules.

- **Players**: install instructions, compatibility, monster compendium and changelog are in the [documentation](https://arnaudpourbaix.github.io/enhanced-creatures).
- **Download**: [latest release](https://github.com/arnaudpourbaix/enhanced-creatures/releases/tag/latest).
- **Developers**: see [DEVELOPMENT.md](DEVELOPMENT.md) to run the generator.
