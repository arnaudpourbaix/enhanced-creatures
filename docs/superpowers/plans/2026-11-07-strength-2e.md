# 2e Strength Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record each 2e strength next to the current (3e/5e) one, and let `GLOBAL_CONFIG.strengthEdition` pick which plays.

**Architecture:** An optional `strength2e` on creature data (creature, variant or adjustment). A small service resolves it inside `creatureService.checkData`, once per creature/adjustment, so the CRE patch, the doc, the XP formula and the AI all read the resolved `strength`/`exceptionalStrength`/`thac0` and never `strength2e`. Default `"3e+"` changes nothing.

**Tech Stack:** TypeScript, vitest, the generator (`npm run generate`), the dashboard (`npm run dashboard`).

**Spec:** [docs/superpowers/specs/2026-11-07-strength-2e-design.md](../specs/2026-11-07-strength-2e-design.md); values in [docs/research/strength-damage-survey.md](../../research/strength-damage-survey.md) ("2e strengths found").

## Global Constraints

- Default `GLOBAL_CONFIG.strengthEdition = "3e+"`: the golden test must pass unchanged (mod/ identical).
- "No bonus" (a `strength2e` without `strength`) plays strength 15, exceptional 0.
- `hit` is applied as `thac0 -= hit` (lower THAC0 = better), only in `"2e"` mode.
- An adjustment that sets its own `strength` or `exceptionalStrength` (and no `strength2e`) is never touched.
- Natural weapons keep the strength bonus (no change to `addNaturalWeapon`).
- No `lib/creatures/<creature>.test.ts` files: test the service with fixtures, verify creatures through generated output.
- Stage explicit paths only (never `git commit -a`); the post-commit hook adds a CHANGELOG line: remove it for internal commits (amend).

## Review Focus

- An adjustment inheriting the creature's `strength2e` but with its own auto-generated THAC0 (its own `level1`): the `hit` correction must apply to the adjustment's THAC0 too, once.
- `"2e"` mode on a creature with `hit` but no THAC0 (autoGenerate.thac0 off, none set): fail loudly, not silently drop the correction.
- A 2e score without exceptional replacing a 3e+ 18/xx (half-ogre 17 → 18, a vampire...): `exceptionalStrength` must be reset to 0, not kept.
- An adjustment with only `exceptionalStrength` (elder minotaur 18/50) counts as its own strength: untouched.
- `strength2e` must never be written to the CRE (it is not in the WeiDU field list): covered by the golden test in Task 2.

**Interfaces:**

  - `export type StrengthEdition = "3e+" | "2e"` in `lib/config/generate.ts`; `GLOBAL_CONFIG.strengthEdition: StrengthEdition` (= `"3e+"`, annotated so tests can assign `"2e"`)
  - `NO_BONUS_STRENGTH = 15` exported from the service

- [ ] **Step 1: Write the failing tests** (`strength-edition.service.test.ts`)

```ts
const source = "MM";
it("3e+ changes nothing", () => {
  const data = {
    strength: 19,
    thac0: 15,
    strength2e: { strength: 18, exceptionalStrength: 100, hit: -1, source },
  };
  strengthEditionService.apply({ data, edition: "3e+" });
  expect(data).toMatchObject({ strength: 19, thac0: 15 });
});
it("2e plays the 2e score and its to-hit correction", () => {
  const data = {
    strength: 19,
    thac0: 15,
    strength2e: { strength: 18, exceptionalStrength: 100, hit: -1, source },
  };
  strengthEditionService.apply({ data, edition: "2e" });
  expect(data).toMatchObject({ strength: 18, exceptionalStrength: 100, thac0: 16 });
});
it("a 2e score without exceptional resets it", () => {
  const data = { strength: 18, exceptionalStrength: 76, strength2e: { strength: 19, source } };
  strengthEditionService.apply({ data, edition: "2e" });
  expect(data).toMatchObject({ strength: 19, exceptionalStrength: 0 });
});
it("no bonus plays strength 15", () => {
  const data = { strength: 18, exceptionalStrength: 40, thac0: 10, strength2e: { hit: 3, source } };
  strengthEditionService.apply({ data, edition: "2e" });
  expect(data).toMatchObject({ strength: NO_BONUS_STRENGTH, exceptionalStrength: 0, thac0: 7 });
});
it("an adjustment inherits the creature's 2e to-hit on its own THAC0, not its score", () => {
  const parent = {
    strength: 18,
    strength2e: { strength: 18, exceptionalStrength: 100, hit: -1, source },
  } as CreatureData;
  const data = { thac0: 13 };
  strengthEditionService.apply({ data, parent, edition: "2e" });
  expect(data).toEqual({ thac0: 14 }); // the score comes from the creature's own (resolved) data
});
it("an adjustment with its own strength is untouched", () => {
  const parent = { strength2e: { strength: 18, hit: 2, source } } as CreatureData;
  for (const own of [
    { strength: 18, thac0: 13 },
    { exceptionalStrength: 50, thac0: 13 },
  ]) {
    const data = { ...own };
    strengthEditionService.apply({ data, parent, edition: "2e" });
    expect(data).toEqual(own);
  }
});
it("an adjustment's own strength2e wins over the creature's", () => {
  const parent = {
    strength2e: { strength: 18, exceptionalStrength: 100, hit: -1, source },
  } as CreatureData;
  const data = {
    thac0: 12,
    strength2e: { strength: 18, exceptionalStrength: 100, hit: 1, source },
  };
  strengthEditionService.apply({ data, parent, edition: "2e" });
  expect(data).toMatchObject({ strength: 18, exceptionalStrength: 100, thac0: 11 });
});
it("a to-hit correction without THAC0 fails", () => {
  const data = { strength: 19, strength2e: { strength: 18, hit: 1, source } };
  expect(() => strengthEditionService.apply({ data, edition: "2e" })).toThrow(/THAC0/);
});
```
